I Just Wanted To Send An Email

February 18, 2026 Development

I was trying to consolidate everything. Keep it all in one place.

The Plan

Person pays $1 → Gets access code → I email them the code. Basic e-commerce stuff.

AWS Said No

Applied for SES production access. Denied.
Wrote a more detailed application. Denied again.

Amazon denied my production level access for sending emails. Not once, but twice.

I get it. They deal with spam all day. The filters exist for good reasons. But I'm sitting here with working Stripe webhooks, valid purchase confirmations, and no way to send them.

So much for consolidation. I guess I had to... resend.

What I ended up using: Resend API. Added DNS records. Got an API key. Sent emails. Took 10 minutes.
