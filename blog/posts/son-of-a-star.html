Son of a *

Seven months later. The AI is better. I'm a little older. I missed this, and the project was a wreck when I came back.

Seven Months

The last post was March 1. I tore the game down to one config file, said I'd keep going, and then I didn't.

Life. Other work. The usual. I got a little older. I kept thinking about Yooba standing in a burning village and then I'd close the tab. Tonight I opened it again because I missed working on it. That's the whole reason. I missed the stupid thing.

The AI is better than it was in March. That's the part I didn't expect to feel so clearly. Back then every session was a fight to keep it from inventing a second source of truth. Now it can read the repo, look at a git diff, and tell me what I actually broke. I still have to watch it. I just don't have to translate as much.

It Was Ruined

I came back and the site was on GitHub Pages. Static files. A CDN. No Docker, no nginx, no Flask. The project I left in March assumed all of that was sitting behind the domain.

I loaded the page. The console was a graveyard.

  • The analytics script, /umami/script.js, 404.
  • The start button calling /paywall/check-access, 404.
  • Unity trying to boot SickOfIt.framework.js.gz and choking on the first byte.
  • Then unityFramework is not defined, because the framework script never parsed.
  • The data file, about 4 MB, still gzipped, because the server never said Content-Encoding: gzip.

GitHub Pages will happily hand you a gzip file. It will not tell the browser to unzip it. Unity's .gz build expects that header. Without it, the browser tries to run compressed bytes as JavaScript. Invalid token. Game dead. The homepage was also asking a server that doesn't exist whether I was allowed to press play.

I built a game, left for seven months, and came back to a loading screen that couldn't load.

Putting It Back Together

First we pulled the dead services out. Umami was on every page. There was a stats dashboard, a JavaScript wrapper so the Unity build could phone home, three markdown guides, and a Postgres container in the compose file. One commit. About 1,700 lines deleted. The Stats link in the blog nav went with it.

The paywall went too. The start button was fetching an access check and, if you had paid, sending you to /Game/ instead of just starting. There were Buy and Take pages whose only job was checkout and redeem codes. Nginx was locking /Game/ behind that login. None of that can run on a static host, and I didn't want it in front of the game anymore. Click to start means click to start.

There was also a live email API key sitting in the dev compose file as a default value. That came out. A key that has lived in a repo is burned, so that one gets rotated.

The Gzip Costume Change

I didn't trust GitHub Pages with gzip headers, so I exported the build a different way. The files are still compressed. They're named .unityweb. The Unity loader looks for its own marker in the bytes and decompresses them in JavaScript. The server just serves a file. That's the whole trick.

v100 came out. v104 went in. Data, framework, wasm, a pile of Addressables bundles. The page at /Game/ was still asking for the old names:

  • SickOfIt.framework.js.gz
  • SickOfIt.wasm.gz
  • SickOfIt.data.gz

All 404. GitHub's 404 is an HTML page. The loader tried to execute that HTML. Unexpected token '<'. Then unityFramework is not defined again, same crash, new costume.

The fix was three strings. Point the page at the files that are actually in Game/v104/SickOfIt/Build/. .data.unityweb, .framework.js.unityweb, .wasm.unityweb. The game comes up.

I Forgot I Built Rewind

Then I played it.

I rewound. The level ran backwards. Shots unspread. I went all the way to the start, let go, and I couldn't fire. That's the bug that made me go look.

The game has its own clock. GameClock can run time in reverse. A timeline records transforms, rigidbody velocity, whether an object is even active. Projectiles pause while you're scrubbing, because their lifetime reads that clock instead of Unity's. I built this in the spring and then I left, and I did not remember that it feels good.

It feels good. You hold rewind and the mess you just made unspools. It's the first time I've come back to this game and thought: oh. That's fun. I made that.

The shooting bug is the clock being honest and the cooldown being sloppy. Fire rate is checked against GameClock time, which is the right idea, except the last-shot timestamp doesn't rewind with everything else. Scrub back to zero and the last shot is still sitting in the future. The game thinks you're on cooldown until time catches up to a shot you already undid. I'll fix it. I'm glad I found it by playing, and I'm gladder the rewind is real.

Still Here

Seven months. A little older. The AI got better while I was gone, which is lucky, because I needed it to help me read my own wreckage. The site is a pile of static files now. That's a downgrade from the Docker setup and it's also the thing that made the game load again.

Son of a *. I missed this.
